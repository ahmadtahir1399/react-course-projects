## ✨ About

The projects I built while working through the **Chai aur React** series by [Hitesh Choudhary (Chai aur Code)](https://www.youtube.com/@chaiaurcode). Each folder is a separate Vite app that focuses on one React concept, starting from how React renders and ending with global state in Redux Toolkit.

## 📚 Projects

| # | Folder | What I learned |
|---|---|---|
| 01 | [`customReact`](./customReact) | How React renders elements under the hood: a tiny custom `render()` |
| 02 | [`02counterproject`](./02counterproject) | `useState` basics and how state updates work |
| 03 | [`03tailwindprops`](./03tailwindprops) | Tailwind setup and passing props to reusable cards |
| 04 | [`04bgcolorchanger`](./04bgcolorchanger) | Event handling and state-driven styling |
| 05 | [`05passwordgenerator`](./05passwordgenerator) | `useCallback`, `useEffect`, `useRef`, clipboard API |
| 06 | [`06currencyproject`](./06currencyproject) | Custom hooks (`useCurrencyInfo`) and API calls |
| 07 | [`07reactrouter`](./07reactrouter) | React Router: layouts, nested routes, loaders, params |
| 08 | [`08miniContext`](./08miniContext) | Context API basics: login and profile |
| 09 | [`09themeswitcher`](./09themeswitcher) | Context for a dark/light theme toggle |
| 10 | [`10todocontextLocal`](./10todocontextLocal) | Todo app with Context + localStorage |
| 11 | [`reduxToolkit`](./reduxToolkit) | Redux Toolkit: store, slices, `useSelector`, `useDispatch` |

## 🚀 Run a project

```bash
git clone https://github.com/ahmadtahir1399/react-course-projects.git
cd react-course-projects/07reactrouter   # any project folder
npm install
npm run dev
```
